# DreamDash · 梦幻跑跑

浏览器 3D 跑酷小游戏，单文件 `index.html` + 本地素材，无 npm、无构建。

- 在线游玩：https://dreamdash-arch.github.io/DreamDash/
- 单人模式：收集星星 / 金币 / 发光蘑菇，冲过终点结算
- 双人竞速：先到终点者获胜，两人距离拉开时自动左右分屏

## 操作

| | 移动 | 跳跃 | 角色技能 | 问号道具 |
|---|---|---|---|---|
| P1 | `A` / `D` | `W` 或 `Space` | `Q` | `S` |
| P2 | `←` / `→` | `↑` | 小键盘 `0` | `↓` |

- `ESC` 暂停
- 选角界面：P1 用 `A`/`D`，P2 用 `←`/`→`，`Space` 确认

## 局域网 1v1 联机

在**其中一台电脑**上运行主机程序（零依赖，只用 Python 标准库）：

```bash
python3 server.py            # 默认端口 8000
python3 server.py --port 9000
```

启动后终端会打印可用的局域网地址，例如 `http://192.168.1.23:8000/`。

1. 主机：浏览器打开该地址 → 「局域网联机」→「创建房间（我是主机）」
2. 页面会显示一个带房间码的链接，把它发给对方
3. 客机：用浏览器打开这个链接即可自动加入
4. 主机点「开始选角」，双方各自用 **A / D** 选角色、按空格（或等房主确认）后开始

联机时**两台电脑都用 WASD** 操作自己那台机器上的角色：

| 操作 | 按键 |
|---|---|
| 左右移动 | `A` / `D` |
| 跳跃 | `W`（或空格） |
| 角色技能 | `Q` |
| 问号道具 | `S` |

> 主机权威同步：主机跑物理并广播状态，客机只上传按键并渲染结果，所以客机自己的操作有约 30–60ms 延迟。
> 房间数据只存在内存里，主机程序退出后房间即失效。

## 本地运行

因为要加载本地 GLTF 角色模型，建议用本地服务打开：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/index.html
```

直接双击 `index.html` 也能玩，但浏览器会拦截本地模型文件，角色会回退成程序化模型。

局域网联机**必须**用 `server.py` 启动（GitHub Pages 是静态托管，跑不了服务端）。
